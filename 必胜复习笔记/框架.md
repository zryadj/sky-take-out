##### 代理对象

 是 **用来包装（代理）目标对象** 的对象。它**拦截** 方法调用，并**增强或修改** 目标对象的行为。在 Java 中，代理对象常用于 **日志记录、权限校验、事务控制、远程调用** 等场景。

| **代理方式** | **适用场景**                       | **实现方式**             |
| ------------ | ---------------------------------- | ------------------------ |
| **静态代理** | **代理对象固定**，编译时生成代理类 | **手写代理类**           |
| **动态代理** | **代理对象动态创建**，运行时生成   | **JDK 动态代理 / CGLIB** |

| **代理方式**       | **适用场景**           | **实现方式**               | **是否支持无接口类** |
| ------------------ | ---------------------- | -------------------------- | -------------------- |
| **静态代理**       | **代理类固定**         | 手写代理类                 | ❌ 需要接口           |
| **JDK 动态代理**   | **目标对象实现了接口** | `Proxy.newProxyInstance()` | ❌ 需要接口           |
| **CGLIB 动态代理** | **目标对象没有接口**   | `Enhancer.create()`        | ✅ 支持无接口         |
